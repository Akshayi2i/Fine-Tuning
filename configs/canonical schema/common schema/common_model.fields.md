# Common model — field reference

Generated by `scripts/build_common_model_fields_md.py` from `common_model.json` v1.4.0 and `lob_schema_map.yaml`. Edit those files, not this one.

**Inclusion rule:** A field, block or coverage code belongs here when two or more LOBs print it. A concept printed by one LOB only goes in that LOB's own block or coverage_codes.yaml.

**Leaf types.** Every value is a `FieldValue` (`raw`, `parsed`, `confidence`, `page_ref`, `flagged`) or a typed variant that restricts `parsed`:

- `DateValue`: A date. `parsed` is MM/DD/YYYY (SPEC_21 D1), or null when the printed wording is not a date (e.g. a retroactive date printed 'Full Prior Acts').
- `MoneyValue`: An amount of money. `parsed` is a number, or null when the printed wording is not an amount ('Included', 'Not Covered'); whether the coverage applies is recorded in `included`.
- `PercentValue`: A percentage. `parsed` is a number: 5% -> 5.
- `NumberValue`: A count, year or measurement. `parsed` is a number.
- `BoolValue`: A yes/no fact. `raw` is the printed mark or wording ('X', 'Yes', 'Included').
- `YearValue`: A calendar year (model year, year built). `parsed` is an integer 1900-2100.
- `StateValue`: A US state or territory. `parsed` is the two-letter USPS code ('New York' -> 'NY').
- `PostalCodeValue`: A US ZIP code. `parsed` is 5 digits or ZIP+4 ('12180-1234').
- `NaicValue`: An NAIC company code. `parsed` is 5 digits, leading zeros kept.
- Variants with a fixed list of `parsed` values: `TransactionTypeValue`, `CoverageTriggerValue`, `IncludedValue`, `ValuationValue`, `AdmittedStatusValue`, `DriverStatusValue`.

Plain strings or enums, not FieldValues, are structural keys: `coverage_id`, `coverage_code`, `limit_type`, `deductible_type`, `part`, `part_id`, `unit_id`, `applies_to`, `role`, `lob`.

# Default audit rules

Every LOB schema copies these into its `fideon:audit_rules`. A rule is skipped when the values it needs are absent.

- `policy.effective_date < policy.expiration_date`
- `months_between(policy.effective_date, policy.expiration_date) == policy.term_months`
- `policy.effective_date <= document.transaction_effective_date <= policy.expiration_date`
- `claims_made_terms.retroactive_date <= policy.effective_date`
- `len(coverages[].limits[]) >= 1`
